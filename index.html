Smart Marketplace

A full-stack e-commerce marketplace where buyers search, buy and track orders, and sellers manage listings and see their analytics. Personalised recommendations and sales forecasts come from separate Python ML services, so the core shopping flow keeps working even if a model is down.

  • Five Deno/Hono microservices (auth, products, orders, users, search) with clear REST contracts
  • Normalised PostgreSQL schema with migrations, and full-text search and filtering with Elasticsearch
  • Stripe checkout in test mode, with webhooks for redirect-based payments
  • scikit-learn recommender and sales forecasting served through FastAPI
  • JWT access/refresh tokens, bcrypt hashing, input validation and rate limiting

Real-time · multiplayer

Collab Whiteboard

A real-time whiteboard for multiple users. Anyone who opens the same room link sees everyone else's drawings and cursors appear live, even when two people draw at the same moment.

  • CRDT-based state with Yjs, so simultaneous edits merge deterministically without locks or hand-written conflict logic
  • Undo/redo scoped to each user, so Ctrl+Z never undoes someone else's strokes
  • Offscreen-canvas rendering keeps drawing smooth with hundreds of strokes on the board
  • Thin WebSocket relay server that saves each room to disk with LevelDB. Containerised for Fly.io
  • Pen, shape, text and eraser tools, pan and zoom, live presence and a rooms landing page
